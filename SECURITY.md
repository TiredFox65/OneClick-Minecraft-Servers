# Security Policy

## Supported Versions

Security fixes are intended for the latest release only. The current supported
release is:

| Version | Supported |
| ------- | --------- |
| 2.0     | Yes       |
| 1.07    | Yes       |
| Older   | No        |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately using
[GitHub's private vulnerability reporting](https://github.com/TiredFox65/OneClick-Minecraft-Servers/security/advisories/new).
Do not open a public issue or discussion containing exploit details.

Include, where possible:

- The affected version and Windows version.
- A description of the issue and its potential impact.
- Steps to reproduce it, with a minimal proof of concept if needed.
- Any relevant logs or screenshots, after removing passwords, tokens, IP
  addresses, and other personal or sensitive information(optional, for extra help potential).

You can expect us to fix the vulnerabliltity as soon as possible. We will work with you on a fix and coordinated
disclosure. Please allow us a reasonable opportunity to investigate
and release a fix before sharing vulnerability details publicly.

If private vulnerability reporting is unavailable, contact the repository
owner through [their GitHub profile](https://github.com/TiredFox65). Do not
publish sensitive details while seeking a private reporting channel.

Reports that do not represent a security vulnerability may be directed to the
repository's public issue tracker.
